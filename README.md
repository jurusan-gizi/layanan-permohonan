# Layanan Permohonan — Gizi-Link

Form permohonan mahasiswa (Angsuran UKT, Ket. Tidak Menerima Beasiswa, Pengambilan Data Awal,
Surat Pengembalian). Data diri diambil dari login Gizi-Link, tersimpan di Google Sheet,
lalu mahasiswa menekan **Kirim ke WA** untuk memberi tahu admin akademik.

- `index.html`, `app.js`, `style.css`, `icons/` — tampilan
- `config.js` — isi `API_URL` (URL /exec Apps Script)
- Server: `Code.gs` di Google Sheet "Layanan Permohonan Gizi-Link"
